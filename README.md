# 🤖 Robot Maze Escape

An interactive **Reinforcement Learning project** built with Python and Streamlit. The player controls a robot through a maze while a **Q-Learning AI** learns the best path to the goal.

## ✨ Features

* 🎮 Interactive 4×4 maze
* 🤖 Robot movement controls
* 🧠 Q-Learning AI
* 🟢 Visual AI learned path
* 📊 Q-Table visualization
* 🏆 Goal detection and celebration
* 🔄 Restart maze option

## 🛠️ Technologies

* Python
* Streamlit
* NumPy
* Pandas
* Q-Learning

## 🚀 Run the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/robot-maze-escape.git
cd robot-maze-escape
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
